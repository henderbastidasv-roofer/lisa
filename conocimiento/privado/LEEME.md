# Documentos privados de tu compañía

Aquí van notas cortas de tus propios documentos: manuales de las marcas que instalas, manuales que compraste, tus procedimientos.
- Claude Code los convierte en notas `.md` por tema, **cortas**: Lisa habla por teléfono, y un prompt muy largo la hace más lenta para contestar.
- **Esta carpeta nunca se sube a GitHub** (está en `.gitignore`). Se queda en tu computadora y en tu agente de Retell.
- Pon solo documentos que tengas derecho a usar.
- Después de agregar o cambiar algo, corre `npm run agente`.
