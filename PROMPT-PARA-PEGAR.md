# El prompt para instalar a Lisa

1. Abre **Claude Code**: en la app de Claude, la pestaña **Code**.
2. Elige o crea una carpeta que **no** esté dentro de OneDrive, iCloud ni Dropbox. Por ejemplo, `C:\Users\<tu usuario>\Proyectos`.
3. Copia y pega esto:

```
Quiero instalar Lisa, el agente de llamadas para mi compañía de techos.

Clona https://github.com/henderbastidasv-roofer/lisa en una carpeta nueva llamada "lisa" dentro de esta carpeta, entra a ella y sigue el archivo INSTALAR.md paso a paso conmigo.

No sé programar: explícame todo simple, una cosa a la vez, dime cuánto cuesta antes de cualquier prueba que gaste saldo, y nunca me pidas que pegue claves en el chat.
```

Eso es todo. Claude Code te va a hacer preguntas de tu compañía, te va a decir qué cuentas crear y te va a avisar antes de cada paso importante.

¿Todavía no quieres un número? Igual puedes instalarla: Lisa queda lista, la oyes desde el navegador y el número lo conectas otro día.
